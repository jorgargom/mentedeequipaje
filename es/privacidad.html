Alojamiento web mediante GitHub Pages

Esta web se publica mediante GitHub Pages. Cuando accedes, el proveedor de alojamiento puede tratar datos técnicos de conexión, como la dirección IP, la fecha y hora de acceso, la página solicitada, el volumen de datos transferidos y la información del navegador y del sistema operativo. Este tratamiento permite ofrecer, proteger y mantener la web. Puedes consultar la información de GitHub Pages y la política de privacidad de GitHub.

Contacto por correo electrónico

Si escribes a mentedeequipaje@gmail.com, se tratarán el contenido del mensaje y los datos de contacto que facilites para responder a tu consulta y a posibles comunicaciones posteriores. El correo se recibe y gestiona mediante Gmail/Google. Evita enviar información especialmente sensible si no es necesario.

Fuentes externas y enlaces

Esta web carga tipografías de Google Fonts. Al cargar la página, el navegador se conecta a servidores de Google y puede transmitir, entre otros datos, tu dirección IP. Puedes consultar la política de privacidad de Google.

Los enlaces a Instagram, YouTube y Spotify llevan a servicios externos. Sus políticas de privacidad se aplican cuando accedes a esas plataformas.

Cookies y analítica

Según la configuración actual, esta web no utiliza cookies de análisis o publicidad ni herramientas de medición de audiencia. Tampoco utiliza formularios de contacto.

Tus derechos

De acuerdo con la normativa aplicable, puedes tener derecho a acceder a tus datos, rectificarlos, solicitar su supresión o limitación, oponerte a determinados tratamientos y solicitar la portabilidad. También puedes presentar una reclamación ante una autoridad de protección de datos. Para ejercer tus derechos, escribe a la dirección indicada arriba.
