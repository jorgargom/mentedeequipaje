# Mente de Equipaje

Web editorial del proyecto Mente de Equipaje.

## Estructura

- `index.html`: página principal y navegación por secciones.
- `css/styles.css`: estilos, diseño adaptable y tipografía.
- `js/main.js`: menú móvil y año del pie de página.
- `assets/icons/favicon.svg`: icono del sitio.
- `CNAME`: dominio personalizado de GitHub Pages.

## Publicación

El sitio está preparado para GitHub Pages. La configuración de Pages y los registros DNS se gestionan por separado en GitHub y en el proveedor del dominio.
