# Mente de Equipaje

Web editorial del proyecto personal Mente de Equipaje: historias, reflexiones y conversaciones sobre experiencias humanas, cambios de etapa, adaptación, identidad y aprendizaje.

## Estructura

- `index.html`: página principal y navegación por secciones.
- `css/styles.css`: estilos, diseño adaptable, tipografía e identidad visual.
- `js/main.js`: menú móvil accesible, actualización del año y animaciones discretas.
- `assets/images/`: imágenes editoriales y recursos para compartir.
- `assets/icons/favicon.svg`: icono del sitio.
- `site.webmanifest`, `robots.txt`, `sitemap.xml`: configuración del sitio.
- `CNAME`: dominio personalizado de GitHub Pages.

## Criterios técnicos

- HTML, CSS y JavaScript nativos, sin frameworks ni dependencias de ejecución.
- La ilustración de la maleta se construye con HTML y CSS; no depende de imágenes externas.
- La navegación funciona con ratón y teclado.
- El contenido permanece visible si JavaScript no está disponible.
- Las animaciones respetan `prefers-reduced-motion`.
- Las fuentes DM Sans y Playfair Display se cargan desde Google Fonts con alternativas locales.

## Publicación

El sitio está preparado para GitHub Pages. Los cambios de esta rama deben revisarse antes de integrarse en `main`.
